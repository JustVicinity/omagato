# Domain docs

OmaGato is a single-context repository. Domain terms belong in the root `GLOSSARY.md`; architecture decisions belong in `docs/adr/`.

Before domain work, read the glossary and ADRs relevant to the change. If they do not exist, proceed without them. Create them when terms or decisions are actually resolved.

Use the glossary's terms in issues, tests, and proposals. Call out a conflict with an existing ADR before changing that decision.
