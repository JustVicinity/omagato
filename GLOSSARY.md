# OmaGato

OmaGato brings Elgato device controls into the Omarchy desktop.

## Language

**Device profile**:
The keys, pages, brightness, dial settings and application rules belonging to one physical Stream Deck.
_Avoid_: Global layout, app profile

**Shared template**:
The initial settings used by decks that do not yet have their own device profile.
_Avoid_: Default device, master deck

**Application rule**:
An association between an application and the page shown when that application becomes active.
_Avoid_: Smart profile, device profile

**Detected device**:
A device visible to the operating system whose controls may still be unavailable.
_Avoid_: Ready device

**Ready device**:
A detected device with controls currently exposed by a working integration.
_Avoid_: Fully supported device
