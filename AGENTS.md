## Agent skills

### Issue tracker

Track OmaGato work in GitHub Issues. Read `docs/agents/issue-tracker.md` before creating, changing, or triaging issues.

### Triage labels

Use the five standard triage labels. Read `docs/agents/triage-labels.md` when assigning a triage state.

### Domain docs

Use one root glossary and root-level ADRs. Read `docs/agents/domain.md` before naming domain concepts or changing architecture.
